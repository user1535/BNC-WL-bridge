# xWL 진입·시장 교환·브리지 방향

2026-11-05 결정. WorldLand의 네이티브 WL은 xWL 발행 시 소각하고 시장 교환에서는 거래 자산으로 사용하며, 브리지 자산은 WorldLand의 xWL과 BSC의 wWL로 정한다.

| 방향 | 비율 | 실행 |
| --- | --- | --- |
| WL → xWL | 온체인 1:1 | 사용자가 WL을 소각하면 WorldLand 계약이 같은 수량의 xWL을 발행한다. |
| xWL → WL | 거래 시점의 시장가 | 같은 WorldLand 체인에서 당사자끼리 수량·가격을 정해 xWL과 기존 WL을 각각 전송한다. |
| xWL ↔ wWL | 양방향 1:1 | 기존 V2 브리지에서 출발 토큰을 소각하고 목적지 토큰을 같은 수량으로 발행한다. |

## WL 소각과 xWL 발행

사용자가 보낸 네이티브 WL을 합의된 방식으로 소각하고, 실제 소각한 수량과 같은 xWL을 지정 수신자에게 발행한다. 소각·발행·이벤트는 한 거래로 처리한다. 어느 한 단계가 실패하면 둘 다 되돌린다. 가스비는 별도다. 0 소각이나 정확히 환산할 수 없는 수량은 거부한다.

기존 전송 규칙에서 회수 경로가 없는 소각 주소를 사용해 WL을 유통에서 제외하는 방안을 우선 검토한다. WL 측과 대상 주소, 회수 불가능성, 탐색기·공급량 집계에서의 의미를 확인한다. 이 방식과 노드가 공식 공급량을 차감하는 프로토콜 소각은 구분한다. 진입에 사용된 WL은 운영 지갑 수익이나 시장가 교환의 유동성으로 배정하지 않는다.

## 같은 체인 직접 거래

초기 범위는 거래 당사자가 가격과 수량을 합의하고 지갑에서 WL과 xWL을 각각 전송하는 방식이다. 두 전송은 독립적으로 확정되므로 선송금 위험이 있다. 예를 들어 두 사람이 10 xWL을 8 WL에 거래하기로 하면 두 자산을 각자의 지갑에서 상대 주소로 보낸다. 브리지 증명은 xWL을 BSC로 옮기거나 되돌릴 때 사용한다.

원자적 교환 계약, DEX와 유동성 풀은 후속 검토 대상이다. [단계와 완료 조건](bidirectional-burn-mint-direction-20261103.md#24-단계와-완료-조건)

## 기존 V2 연결

새 배포에서 WorldLand 쪽 브리지 자산을 xWL로 연결하고 BSC 쪽 자산을 wWL로 연결한다. V2의 소각 이벤트·도메인, MPT 구성, 실제 RISC Zero 증명과 SDK 검증, 목적지 청구·중복 방지 흐름을 재사용한다. 증명은 배포된 토큰 주소와 체인에 묶이므로 기존 세션의 소각 증거를 새 토큰으로 청구하는 용도로 쓸 수 없다.

xWL의 진입 발행과 브리지 반환 발행은 별도로 기록한다. 진입 발행은 실제 WL 소각 수량에, 반환 발행은 검증된 wWL 소각 ID와 수량에 각각 제한한다. 소각 단계 또는 발행 단계 실패 시 전체 거래의 원자성, 잘못된 토큰 주소의 청구, 같은 소각 ID 재제출은 연동 검사 항목이다.

## 면담과 구현 순서

1. WL 팀과 데이터 API, WL 소각 방식·발행 정책, 일반 전송 환경 및 개발망을 확인한다.
2. 로컬 격리 세션에서 WL 소각 → xWL 발행과 소각·발행량 일치를 검증한다.
3. xWL ↔ wWL 양방향을 기존 증명·청구 경로에 연결하고, 반환한 xWL을 기존 WL과 직접 거래하는 흐름을 검증한다.

이번 결정은 [이전 네이티브 WL burn·mint 안](native-wl-burn-mint-spec.md)의 적용 방향을 대체한다. 새 방향은 네이티브 WL의 재발행 대신 xWL을 발행한다. 기존 전송 규칙으로 합의한 소각을 구현할 수 있으면 프로토콜 변경 없이 진행할 수 있다. 현재 완료 범위는 설계·면담 자료 갱신이며, 기존 V2 실험 결과는 [실행 문서](burn-mint-runtime.md)에 기록돼 있다.
