# 내부 서명 xWL ↔ wWL 브리지 · 로컬 완료 체크리스트

기준일: 2026-11-19. 사용자가 기존 RISC Zero 필수 경로를 대체하고 이 방향을 로컬에서 끝까지 구현·검증하도록 승인했다. 이 문서를 다음 실행의 재개 지점으로 사용한다.

## 확정 범위

- 체인 A(로컬 31337): WL을 계약 Vault에 예치하고 1:1 xWL을 발행한다. xWL은 자유 전송·승인·대리 전송할 수 있다. 상환용 xWL 소각으로 WL을 지급한다.
- 브리지: xWL 또는 wWL의 브리지용 소각을 서버가 확인하고 EIP-712 메시지에 내부 서명한다. 이용자가 반대 체인에 직접 제출해 반대편 토큰을 같은 수량으로 발행받는다.
- 체인 B(로컬 31338): wWL을 자유 전송·승인·대리 전송할 수 있다. 반환은 wWL 소각 → 서버 서명 → 체인 A의 xWL 발행 → 선택적으로 WL 상환이다.
- 새 경로에는 RISC Zero, MPT 생성·검증, 운영자 루트 등록이 없다. 원본 이벤트·서명 내용·서명·청구 결과는 공개한다.
- 운영자·RPC를 신뢰한다. 목적지 계약은 원본 체인의 합의·최종성을 독립 검증하지 않는다. 내부 키가 잘못 사용되면 허위 발행을 승인할 수 있다.
- 테스트용 공개 Anvil 계정만 사용한다. 자산 거래는 브라우저에서 서명·직접 제출한다. 개인 키·실자산·외부 체인 배포는 사용하지 않는다.
- 기존 `results/prototype-risc0`, `results/wl-vault-v1`, `results/xwl-entry-v1` 세션과 과거 증명은 보존한다.
