3. RISC0 연산 증명 요청

RISC0 연산 증명 · 잠금 또는 소각 후 증명을 요청하세요.

증명은 서버의 RISC0 SDK에서 검증합니다. 청구 전 다시 확인하며, 생성 중에는 잠시 기다려 주세요.

잠금 또는 소각 거래의 상태를 조회하면 이벤트 ID가 입력됩니다.

4. BNB에서 소각한 자산 반환 청구

반대 체인에서 받은 패키지를 이 체인에서 청구합니다.

패키지는 준비되면 화면에 자동으로 불러옵니다. 파일 저장은 아래 다운로드 버튼으로 할 수 있으며, 청구에는 다운로드가 필요하지 않습니다.

서버가 확인한 거래 블록 root를 등록합니다. RISC0 연산 증명 검증 후 연결한 지갑으로 직접 청구합니다.

공개 감사·전체 거래 기록

감사 상태 조회 중

두 체인의 거래 이벤트와 증명 작업을 기록합니다. 감사 해시는 체인에 남으며, 원본 기록의 진위 자체를 증명하지는 않습니다.

서버 운영자와 RPC를 신뢰하는 로컬 시제품입니다. RISC0는 MPT·이벤트 연산을 증명하며 SDK에서 검증합니다. 컨트랙트는 MPT·이벤트·중복 청구를 검증합니다. 실제 체인 합의 인증과 실자산 배포는 지원하지 않습니다.
