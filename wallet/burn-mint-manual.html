Burn & Mint 사용 설명서

WorldLand와 BSC 역할을 하는 두 로컬 테스트 체인에서 사용합니다.

방향을 선택하고 위에서부터 진행하세요

  1. WL → wWL 또는 wWL → WL을 열고 데모 지갑을 연결합니다.
  2. 소각 수량과 수신자를 입력하고 미리보기 아래에서 서명합니다. 영수증이 확인되면 ✓ 소각 완료가 표시됩니다.
  3. 증명을 요청합니다. 실제 RISC Zero 증명 생성과 SDK 검증이 끝나면 ✓ 증명 검증 완료가 표시됩니다.
  4. 수신자 지갑에서 발행을 미리 보고 서명합니다. 목적지 거래가 확인되면 ✓ 발행 완료가 표시됩니다.

이전 소각 이어가기

같은 방향을 열고 지갑을 연결하면 내 소각 기록에 소각한 거래와 내가 받을 거래가 표시됩니다. 각 거래의 소각량, 발행량, 증명 상태를 보고 이어갈 거래를 선택하세요. 증명을 요청하지 않은 소각도 체인에서 찾습니다.

다른 지갑에서 진행한 소각이나 발행을 확인하려면 목록의 새로고침을 누르세요. 저장한 증명 JSON은 증명 단계에서 올릴 수 있습니다.

거래가 처리 중이면 화면에서 영수증을 확인합니다. 필요하면 미확인 거래 상태 조회를 누르세요. 증명 요청이 실패한 경우에는 같은 소각 ID로 다시 요청합니다.

전송, 토큰 사용 승인, 대리 전송 및 감사 기록은 토큰 거래·감사 기록에서 확인할 수 있습니다.

서버와 RPC를 신뢰하는 로컬 모델입니다. 서버 SDK가 RISC Zero 연산 증명을 검증하고 목적지 계약은 운영자가 등록한 root를 기준으로 영수증과 소각 이벤트를 확인합니다.
